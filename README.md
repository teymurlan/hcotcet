# House Cleaning — Фотоотчёты (Telegram-бот)

v1.0 — минимальная рабочая версия: `/start` → меню → новый отчёт → объект →
адрес → фото ДО → фото ПОСЛЕ → завершение.

Всё, что описано ниже, делается **в браузере на iPhone** — командная строка
не нужна.

## Что уже сделано за вас

- ✅ Создана база данных Cloudflare D1 `house-cleaning-reports`
  (id `5389b7bb-7610-4f97-a51a-73c698bee84b`) и в неё применена вся схема

  указывающий на созданную базу.

## Что нужно сделать вам (только в браузере)

### 1. Получить токен бота у @BotFather
В Telegram откройте чат **@BotFather** → `/newbot` → задайте имя и юзернейм.
BotFather пришлёт токен вида `123456:ABC-DEF...`. Никому его не показывайте
и никогда не вставляйте в код — он пойдёт только в Cloudflare Secret (шаг 4).

### 2. Загрузить код в GitHub
1. Зайдите на github.com, создайте новый **пустой** приватный репозиторий,
   например `house-cleaning-bot`.
2. На странице репозитория нажмите **Add file → Upload files**.
3. Загрузите все файлы и папки из этого проекта, сохранив структуру
   (`src/index.ts`, `src/db.ts`, `src/telegram.ts`, `wrangler.toml`,
   `package.json`, `tsconfig.json`, `schema.sql`, `.gitignore`).
4. Commit.

### 3. Подключить репозиторий к Cloudflare Workers
1. В дашборде Cloudflare: **Workers & Pages → Create → Import a repository**.
2. Авторизуйте доступ к GitHub, выберите репозиторий `house-cleaning-bot`.
3. Cloudflare сам обнаружит `wrangler.toml` (имя воркера, D1-биндинг `DB`)
   — настройки сборки менять не нужно, просто нажмите **Save and Deploy**.
4. После первого деплоя запомните адрес воркера, он будет вида
   `https://house-cleaning-bot.<ваш-поддомен>.workers.dev`.

### 4. Добавить секреты
В дашборде: **ваш Worker → Settings → Variables and Secrets → Add**.
Добавьте два **зашифрованных (Secret)** значения:

- `TELEGRAM_BOT_TOKEN` — токен из шага 1.
- `TELEGRAM_WEBHOOK_SECRET` — придумайте любую случайную строку
  (например, 20+ случайных букв и цифр). Она нужна, чтобы никто, кроме
  Telegram, не мог слать запросы на ваш webhook.

После сохранения секретов Cloudflare переразвернёт воркер автоматически.

### 5. Проверить, что воркер жив
Откройте в браузере:
`https://house-cleaning-bot.<ваш-поддомен>.workers.dev/health`
Должно вернуться `ok`.

### 6. Подключить Telegram webhook
Просто откройте в браузере (в адресной строке Safari) такую ссылку,
подставив свои значения токена, адреса воркера и секрета:

```
https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://house-cleaning-bot.<ваш-поддомен>.workers.dev/webhook&secret_token=<TELEGRAM_WEBHOOK_SECRET>
```

В ответ Telegram должен вернуть JSON с `"ok":true`.

### 7. Проверить бота
В Telegram откройте вашего бота и отправьте `/start`. Должно появиться меню
с кнопками «📋 Новый фотоотчёт», «🗂 Мои отчёты», «ℹ️ Помощь».

## Структура проекта

```
wrangler.toml       — конфигурация воркера и биндинг базы D1
schema.sql           — схема базы (уже применена, файл для истории)
src/index.ts          — маршрутизация, webhook, сценарий диалога
src/db.ts             — все запросы к D1
src/telegram.ts       — обёртка над Telegram Bot API и клавиатуры
```

## Как это работает

- Состояние диалога каждого сотрудника хранится в таблице `sessions`
  (`idle` → `awaiting_object_name` → `awaiting_address` →
  `awaiting_photos_before` → `awaiting_photos_after`).
- Фото не загружаются в R2 — сохраняется только `telegram_file_id` из
  Telegram, как и просили. Позже фото можно показывать через
  `getFile`/`sendPhoto` по этому `file_id`, без хранения самих файлов.
- У каждого отчёта есть короткий человекочитаемый номер вида `HC-8K3F2Q`
  (`public_id`).
- Webhook защищён секретным токеном (`secret_token` в `setWebhook` +
  проверка заголовка `X-Telegram-Bot-Api-Secret-Token`), открытых
  административных эндпоинтов нет.
